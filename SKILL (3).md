# ViTRA Product Photo

Используй только при запросе `vitra-product-photo` либо товарных фотографий.
1. Для полного комплекта обязательно прочитай `references/full-workflow.txt` — это оригинальный подробный регламент ViTRA Product Photo.
2. Не меняй конструкцию товара, размеры, количество полок/ступеней, органы управления, логотипы и цвета без явного указания.
3. Все выходные картинки должны быть отдельными файлами 750×750; не заменяй комплект одним коллажем.
4. Контекст применения должен быть реалистичным; люди присутствуют только если уместны. Фотографии деталей делай по реальным референсам.
5. Для размеров требуй подтверждённые габариты. Если отсутствуют, не придумывай цифры.
6. Сохраняй в `output/photos/<SKU>/` и кратко перечисляй полученные файлы.
7. Сам Codex — прежде всего кодовый агент. Если у него нет доступного инструмента для генерации изображений, подготовь точные брифы/скрипты или используй явно подключенный инструмент, не утверждая, что фото уже создано.
