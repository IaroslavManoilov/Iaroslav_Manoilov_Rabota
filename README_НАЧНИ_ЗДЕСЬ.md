# Установка в VS Code на Mac

1. Распакуй архив и перенеси **содержимое** папки `ViTRA_Rabota_Codex_Lite` в свою папку `Работа` (не делай лишнюю вложенную папку).
2. VS Code → File → Open Folder → `Работа`.
3. Codex → новый чат. Сообщение: `Прочитай AGENTS.md. Для карточки A017575 используй только skill vitra-product-cards, ничего не записывай в CMS.`
4. Для фотографий: `Используй skill vitra-product-photo. Исходные фото прикреплены. Сохраняй 4 отдельных файла 750x750.`
5. Blender вынеси в отдельный VS Code проект. MCP, добавленный командой `codex mcp add`, является глобальным, даже если этот проект его не использует. Для большей экономии и изоляции при работе с товарами можно временно отключить глобальный Blender MCP: `codex mcp disable blender` (если версия CLI поддерживает); при необходимости включить снова. Проверяй поддерживаемые команды: `codex mcp --help`. Не удаляй инструмент без необходимости.

Сохранены оригинальные полные регламенты. Переключение skills не гарантирует фиксированного объёма токенов; экономия зависит от фактической нагрузки, модели и режима инструментов.
