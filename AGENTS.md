# Работа — ViTRA Product Content

Этот проект служит ТОЛЬКО для подготовки товарных карточек и товарных изображений ViTRA. Blender, другие проекты и их MCP здесь не нужны.

Правила экономии контекста:
- Используй только подходящий skill: `vitra-product-cards` для контента/SEO/JSON; `vitra-product-photo` для фото. Если запрос смешанный, выполняй этапы последовательно.
- Не читай оба полных регламента. Читай только `SKILL.md` выбранного skill, а его `references/full-workflow.txt` — только если конкретное задание требует подробных правил либо перед первой полной выдачей.
- Не делай повторных сетевых поисков при наличии достоверных свежих источников, предоставленных пользователем. Не выдавай кэш за текущую проверку.
- Сначала проверяй точный SKU и исходные данные; никогда не смешивай похожие модели.
- Не выводи в чат длинные логи, большие повторяющиеся JSON, массивы картинок или секреты. Сохраняй итоговые файлы в `output/`, сообщай путь и краткий итог.
- Не входи в CMS, не сохраняй, не публикуй и не меняй товары без отдельного разрешения пользователя. Не считай наличие MCP подтверждением доступа к CMS.
- Инструкции/объяснения на русском; товарные тексты обычно RU, RO, EN.
- Если функции генерации/обработки изображений недоступны, честно укажи ограничение; сам по себе Codex не гарантирует создание фотореалистичных файлов.
