# Что передано и что ещё проверить

Передача подготовлена 2026-10-26. Основание: действующие AGENTS.md, регламенты cards/photo, README-ViTRA.md и точечное чтение старых CMS helpers. Это не аудит всей старой программы и не перечень всех ранее обработанных SKU.

Переданы полные исходные регламенты, актуальные уточнения, portable AGENTS, процедуры simple/parent/create/update/convert, настройка нового аккаунта и Mac, относительная структура, API-карта из исходников, новый read-only connector, проверка формата фото и шаблоны отчётов.

Существующая работа Windows сохранена на месте. При необходимости перенести очередь/отчёты отдельно приватным способом и заново проверить незавершённые задания; не публиковать их в репозитории автоматически.

Mac в этой сессии недоступен. Live-вход нового аккаунта, live-чтение/запись CMS на Mac, новый Content project, создание карточек и поведение media при сохранении ещё не проверены. Первый Codex должен выполнить MAC-SETUP, а запись проверить на явно порученном задании. Инструкции по созданию — процедура для агента через фактический UI/контракт, не готовая автоматическая create-команда.
