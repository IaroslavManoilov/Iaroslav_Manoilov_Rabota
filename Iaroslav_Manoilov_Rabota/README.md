# Iaroslav Manoilov Rabota — ViTRA

Пакет передачи товарного workflow с Windows на MacBook, новый аккаунт ChatGPT, Codex и VS Code. Подготовлен 2026-10-26 по сохранённым правилам проекта ViTRA.

Цель: пользователь отправляет код/ссылку и задание; Codex исследует точную модель, находит карточку, готовит RU/RO/EN, выполняет разрешённые изменения в админке и проверяет сохранённый результат. Поддерживаются простые товары и подтверждённые семьи parent/variants.

## С чего начать

1. Клонировать репозиторий в удобное место на Mac и открыть корень в VS Code/Codex.
2. Отправить Codex текст из `START-HERE.md`.
3. Выполнить `docs/MAC-SETUP.md`: зависимости, новый Content project, вход в CMS, проверка чтением.
4. После настройки отправлять задания из `docs/COMMANDS.md`.

```sh
mkdir -p "$HOME/Projects"
git clone https://github.com/IaroslavManoilov/Iaroslav_Manoilov_Rabota.git "$HOME/Projects/Iaroslav Manoilov Rabota"
cd "$HOME/Projects/Iaroslav Manoilov Rabota"
```

В VS Code: File → Open Folder → выбрать эту папку. В Codex app выбрать её как локальный проект. Одноимённый проект ChatGPT не открывает автоматически локальную папку — это отдельная настройка.

## Границы пакета

Это инструкции и переносимые стартовые инструменты, а не проверенная на вашем Mac установка. Входы, плагины, MCP, Content project и браузерный доступ на новом аккаунте нужно настроить. Создание и обновление CMS выполняет Codex доступным поддерживаемым интерфейсом; готового проверенного автоматического writer для нового Mac здесь пока нет. Контракт создания нельзя угадывать по контракту update.

Новые утилиты не записывают карточки. Старые Windows writer-скрипты не скопированы: в них есть привязки к аккаунту, устаревшие фото-промпты, lifecycle удаления чатов и Windows-зависимости. Вместо их слепого запуска сохранены рабочая схема API и инструкции по проверке в `docs/CMS-ADAPTER.md`. Старую очередь и приватные отчёты не публиковали; они остаются в исходной папке Windows. Это не полная резервная копия старой работы.

## Смена рабочей папки

Перемести весь проект, открой новый корень в Codex/VS Code и повторно активируй окружение. После перемещения пересоздай `.venv` через `bash scripts/bootstrap-macos.sh` (venv может хранить абсолютные пути). Профиль браузера находится внутри `.local/`; сначала закрой отдельный Chrome. В `config/workspace.local.json` измени только настройки, которые сам сделал абсолютными. Не запускай две копии проекта с одной CMS-задачей параллельно.
